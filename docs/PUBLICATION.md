# Decisions before a public release

The owner should confirm:

1. Author names, affiliations, contribution statements, and optional ORCIDs.
2. The code license and manuscript/data reuse terms, with third-party notices preserved.
3. The preferred bibliographic title and citation metadata. Add `CITATION.cff` after these details are settled.
4. Whether and when to change repository visibility and issue a tagged release.

No license has been selected by the import. Repository ownership is not automatically treated as manuscript authorship. No public release, DOI, peer review, or admission-free formalization is claimed.

Before announcing a release, run the full reproduction workflow from a fresh checkout, record the actual cache scope and runner requirements, and review the manuscript-to-formal-statement correspondence. A future release may attach the manuscript PDF and a self-contained archive with checksum manifest.
